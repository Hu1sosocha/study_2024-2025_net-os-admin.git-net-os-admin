Для этого используется команда   mysql_secure_installation .  2.   Как настроить MariaDB для доступа через сеть?  Необходимо отредактировать конфигурационны и&   фа и& л (например,  /etc/my.cnf.d/server.cnf ) и указать параметр   bind-address = 0.0.0.0   или  IP-адрес сервера, а также создать пользователя с правами доступа по сети.  3.   Какая команда позволяет получить обзор доступных баз данных после  входа в среду оболочки MariaDB?  Команда   SHOW DATABASES; .  4.   Какая команда позволяет узнать, какие таблицы доступны в базе  данных?  Команда   SHOW TABLES; .  5.   Какая команда позволяет узнать, какие поля доступны в таблице?  Команда   DESCRIBE имя_таблицы;   или сокращ е? нно   DESC имя_таблицы; .  6.   Какая команда позволяет узнать, какие записи доступны в таблице?  Команда   SELECT * FROM имя_таблицы; .  7.   Как удалить запись из таблицы?  С помощью команды   DELETE FROM имя_таблицы WHERE условие; .  8.   Где расположены файлы конфигурации MariaDB? Что можно настроить с  их помощью?  В каталогах   /etc/my.cnf   и   /etc/my.cnf.d/ .  С их помощью можно настроить кодировку, сетевые параметры, пути  хранения данных, параметры журналирования и другие сво и& ства работы  сервера.  9.   Где располагаются файлы с базами данных MariaDB?  По умолчанию — в каталоге   /var/lib/mysql/ .  10.   Как сделать резервную копию базы данных и затем её восстановить?  –   Для создания используется команда   mysqldump -u root -p имя_БД >  backup.sql . 

---

–   Для восстановления —   mysql -u root -p имя_БД < backup.sql .  –   Для сжато и&   копии можно использовать:   mysqldump -u root -p имя_БД  | gzip > backup.sql.gz , а восстановить через   zcat backup.sql.gz |  mysql -u root -p имя_БД .  5   Список литературы  1.
